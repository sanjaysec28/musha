# Musha Empire — Reference-Matched Website

This is a responsive static website recreated from the supplied Musha Empire mobile reference sheet.

## Included
- Home
- Services
- About
- Gallery
- Offers
- Reviews
- Contact
- Booking
- Warm ivory / gold / brown visual system
- Mobile-first layout
- Responsive desktop layout
- Sticky header + mobile menu
- Smooth page transitions / hover motion
- Booking/contact buttons
- Gallery and service cards
- OpenStreetMap embed on Contact

## Run
Simply open `index.html` in a browser.

For best results, use a local static server such as VS Code Live Server.

## Notes
The photographic content uses remote Unsplash images so the ZIP stays lightweight. Replace the image URLs in `script.js` with your final Musha Empire photography when ready.
